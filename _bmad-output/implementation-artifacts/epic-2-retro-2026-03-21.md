## Challenges

### Discovery Latency
Named graph pattern discovered in Story 2.1 but not fully crystallized until Story 2.6. Handoff notes existed but the pattern took ~2 stories to become internalized. Not a process failure — just the nature of learning a new technology through vertical slices.

### ACL Drift on Container Restart
Pre-existing issue: CSS ACL state drifts when containers restart. Story 2.4 lost time diagnosing before realizing `provision_pods.py` needed re-running. Already documented in memory (`infra_css_volume_drift.md`) but keeps recurring.

### Cognitive Load
8 consecutive stories is taxing for the human in a solo dev + AI pair model. The system holds tight — handoffs, tests, memory all work — but the human must stay sharp for judgment calls. The lightweight handoff pattern (vs full soft-retro) was a correct adaptation to reduce ceremony overhead.

### Soft-Retro Process Optimization
Formal `/soft-retro` skill tried twice, found too heavyweight. Converged on lighter pattern:
- Story end: "anything to report/update in memory/handoff?"
- `/dev-story` includes: "include previous handoffs"
- Captures sufficient value with less cognitive tax
