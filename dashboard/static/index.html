Each pod stores personal learning data and enforces access by default — no external actor can read a pod unless explicitly granted. This page lets you inspect live ACL state, probe access as any identity, and temporarily grant or revoke permissions to demonstrate consent enforcement end-to-end.

Grants show who currently has access (owner and system are always present but hidden here). Test access: select an actor — or "Unknown (no auth)" — and probe to see the live HTTP response. The Grant button is a temporary bypass for demo purposes; production consent flows through the OpenClaw skill.
